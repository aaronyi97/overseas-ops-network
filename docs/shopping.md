# 采购清单与选型标准

> 这份文件写给引导搭建的 AI 和正在采购的你。
> 原则：**给标准和方法，不指定商家**。满足标准的商家都可以，自己比价、自己拍板。

| 项目 | 性质 | 参考价位 |

## 1. 路由器：GL.iNet MT3600BE（Beryl 7）

**为什么是它**：这套方案的全部魔法发生在路由器上——要跑 sing-box 客户端、要做 TPROXY 透明接管、要做防火墙 fail-closed。所以它必须是一台**能 SSH 进去、能装第三方二进制、防火墙规则可编程**的机器。MT3600BE 跑的是 OpenWrt，原生满足全部条件，且是消费级价格。

**采购要点**：

- 型号认准 **GL-MT3600BE**（Beryl 7），别买成同系列其他型号，配置模板不通用
- 官方店或授权渠道即可，全新/二手均可，约 ¥500+
- 到手先确认两件事再开工：能进管理页（默认 `192.168.8.1`）、能 SSH（`ssh root@192.168.8.1`）

**不买什么**：普通家用路由器（不能装 sing-box）、企业级设备（贵且没必要）。

---

## 2. VPS：要"路"好，不要牌子

VPS 的角色是**隧道终点**——你的流量加密送到这里，再转去住宅 IP。它决定的是速度和稳定性。

**选型标准（按优先级）**：

1. **美西优先**：离国内近，延迟天然低。洛杉矶、圣何塞、西雅图一线优先
2. **延迟低**：国内三网 ping 过去，晚高峰也能稳定在 200ms 以内
3. **回程线路好**：回程（VPS → 你）走优化线路，不绕路、不炸。这比"标称带宽 1Gbps"重要得多
4. **能换 IP**：VPS 的 IP 可能被墙，商家后台能自助换 IP（或换一次不贵）是硬需求
5. KVM 虚拟化、root 权限、流量额度够（日常运营 + AI 工具，每月几百 GB 量级足够）

**选型方法（比选哪家更重要）**：

1. **先月付试水**：任何商家第一个月只买月付，不年付、不充大额
2. **三网实测**：拿到 IP 后，用电信/联通/移动的网络（或找在线多节点 ping 工具）分别测：
   - `ping <SERVER_IP>` 看延迟和丢包
   - `mtr <SERVER_IP>`（或 `traceroute`）看路由跳数和绕行
   - **晚高峰（20:00–23:00）再测一遍**——很多线路白天好好的，晚上炸
3. 达标再续费、再考虑长周期；不达标直接换一家，沉没成本只有一个月

**参考价位**：满足上述标准的美西 VPS，约 ¥70–100 / 月。明显低于这个价的"传家宝"套餐通常在线路或超售上有坑。

## 3. 住宅 IP：要"身份"干净独享

住宅 IP 的角色是**你在平台眼里的身份**——平台最终看到的出口 IP 是它。VPS 的 IP 是机房 IP，几百个账号共用是常态，平台早标记烂了；住宅 IP 是美国普通家庭宽带的 IP，这是整个方案值得花钱的部分。

**选型标准（逐条核对，缺一不可）**：

1. **Dedicated / 独享 ISP 代理**：关键词是 "Dedicated ISP" 或 "Static Residential"。**不是**共享池、**不是**动态轮换住宅代理（Rotating Residential）——轮换意味着每次出口 IP 都变，对养号是负资产
2. **固定 IP**：一个 IP 长期归你用，不漂移。IP 频繁变动本身是平台风控信号
3. **流量量级**：每 IP 每月 100GB 左右的公平使用额度，日常运营够用
4. **协议支持**：HTTP/HTTPS 或 SOCKS5 均可（本方案走 VPS 侧 outbound 转发，HTTPS 优先）
5. **地区**：美国，且最好可选城市/ASN——出口 IP 的时区要和你的设备时区一致

**到手必做两件事**：

1. **查 IPQS 分数**（ipqualityscore.com）：Fraud Score 越低越好，个位数为佳。**但注意**：通用查分查不出平台专有标记——我们实测踩过"IPQS 只有 3 分、但某平台专有信号源已把整段 IP 标记"的坑（见 `docs/pitfalls.md`）
2. **A/B 验证**：同设备、同账号、同样使用方式，只换出口 IP，对比目标平台的表现（内容推荐是否正常、AI 回答质量是否被降智、有没有额外验证）。**A/B 对比是终审，查分只是初筛**

**档位参考**：

- 入门：约 $5 / 月 / 1 个 IP——单账号、轻中度运营够用
- 重度：约 $16 / 月 / 5 个 IP 档——多账号矩阵或需要热备 IP 时升级。**注意：只启用 1 个固定生产 IP，其余当备用，不要拿多 IP 做轮换养号**（IP 漂移是风控信号，与养号目标冲突）

**更换成本警告**：换 IP 不是换个数字——平台把"账号 ↔ IP"绑定记档，换了 IP 段才算真换（同供应商内"换槽位不换段"等于没换）。所以第一关就把 IP 选好，比事后换便宜得多。

## 4. 两个订阅为什么都要买

新手最常问："VPS 和住宅 IP 能不能只买一个？"不能。它们是两个不同层的东西：

- **VPS = 路**：加密隧道的终点。没有它，你的流量从家宽到住宅 IP 之间没有受控的加密通道，也没有 fail-closed（防裸奔）的锚点，多设备透明接管也无从谈起
- **住宅 IP = 身份**：平台最终看到的出口。没有它，你从 VPS 机房 IP 直接出海，那个 IP 段通常已被平台标记，等于白搭

缺了路，身份送不到；缺了身份，路通向一个脏出口。**两个都要，每月合计才一百元出头，这是这套方案的核心成本。**

---

## 5. 续费纪律（采购时就要建立）

**固定 IP 断供 = IP 被回收 = 身份没了，而且找不回来。** 真实事故：忘续费一期，旧 IP 直接被释放、无法重新分配，只能新建凭证、换 IP、全链路改配置，还叠加了付款纠纷（详见 `docs/pitfalls.md`）。

下单时立即做三件事：

1. 能开自动续费的全部开自动续费（VPS + 住宅 IP）
2. 日历里设到期前 7 天、前 1 天双重提醒（自动续费也可能扣款失败）
3. 凭证（代理用户名/密码、VPS root）只写进本机 `~/overseas-ops/secrets.txt`，不进任何会外发的地方
