# overseas-ops-network

每月 100 元左右，搭一套属于自己的海外运营网络环境：**路由器层透明接管 + 自建加密隧道 + 独享固定住宅 IP + 双层 fail-closed**。

适合：做 X / TikTok / YouTube 等海外账号运营的人；想稳定使用 Claude Code、ChatGPT 等 AI 工具、不想再被"IP 不干净"折腾的人。

**你不需要懂网络，也不需要读这个仓库。它是写给你的 AI 看的。**

## 怎么用（唯一正确的用法）

把这个仓库链接发给你的 AI 编程助手（Codex / Claude Code / Kimi / DeepSeek 均可），对它说：

> 阅读这个仓库的 AGENTS.md，按剧本把整套环境搭好。

然后你就不用管了：AI 会全程自动施工——命令它自己跑、验收它自己做、每步一句话向你播报进度。你只会在两种时候被打扰：

1. **会断网的高危步骤**：它会提前停下来，先在你电脑上备好本地恢复脚本，等你回复"继续"才动手
2. **必须你亲自做的事**：下单采购、填凭证——它给指引，你照做

## 最终你会得到什么

```
你的电脑 / 手机
   │  连上一个专用 WiFi（路由器），零配置
   ▼
GL.iNet MT3600BE 路由器（透明接管全部流量，隧道断了就断网，绝不裸奔）
   │  VLESS + Reality 加密隧道
   ▼
你自己的美西 VPS
   ▼
你自己的独享固定住宅 IP（美国普通家庭宽带出口）
   ▼
互联网：平台看到的是一个"美国家庭用户"
```

- 出口 IP 固定、独享、干净：不再是几百人共享的机房 IP
- fail-closed：隧道异常 = 直接断网，真实 IP 一秒都不会暴露
- 设备零配置：连上 WiFi 就是海外环境，iPhone 也一样
- 不受家宽/酒店/咖啡馆网络波动影响，路由器重启全自动恢复

## 诚实声明（这个方案做不到什么）

- 不解决支付/账号链路风控（虚拟卡、代充导致的封号与网络无关）
- 不解决设备指纹和行为模式问题（所以第 04 阶段有本机治理）
- 达不到"设备放海外 + 当地家庭宽带"的效果（那是几百美元级投入，适合团队化矩阵运营）

## 开始前必读

1. **搭建过程几乎必然断网**（改路由表、接管流量都会）。请提前准备：一个国内备用网络（手机热点即可）+ 一个国内 AI 助手，断网时让它读 `docs/recovery.md` 接手修复
2. 建议用专门的电脑和手机做运营机，只连这个路由器、不保存任何其他 WiFi 密码
3. 搭完必须做泄露体检（第 03 阶段），全绿之后再注册/登录任何账号
